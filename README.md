## Running the app locally

* Backend: navigate to the backend folder, then run:
  ```
  .\mvnw.cmd spring-boot:run
  ```  
  
* Frontend: navigate to the frontend folder, then run:
  ```
  npm run dev
  ```

* Tests: navigate to the backend folder, then run:
  ```
  .\mvnw.cmd test
  ```
